# Disclaimer

Star-Mesh is a research prototype and protocol specification intended for cryptographic and systems research, protocol analysis, and implementation experimentation. It is not a production service, not a supported end-user application, and not a deployable secure communication platform without additional engineering, review, and hardening.

This repository is designed primarily for researchers, protocol reviewers, and implementers evaluating hybrid post-quantum messaging designs in a controlled setting. The code and accompanying documentation are intended to support reproducibility, technical review, and design validation. They are not a substitute for a production security review or a deployment-ready implementation.

The following applies unless otherwise stated:

- The project is provided for research, evaluation, and experimentation.
- Security properties are scoped to the protocol model and prototype described in this repository and may not hold in an operational deployment environment.
- The implementation may change as the protocol evolves and may contain limitations in hardening, operational controls, authentication, metadata handling, and deployment assumptions.
- No warranty is provided for correctness, reliability, security, or fitness for any particular purpose.
- Any use in production, security-sensitive, or user-facing systems should include a formal threat model, external authentication, operational safeguards, and independent cryptographic review.

Researchers and implementers are encouraged to treat this work as a reference design and a technical artifact for study, extension, and validation rather than as a final or productized security system.

For vulnerability reporting, please follow the process in [SECURITY.md](SECURITY.md).
